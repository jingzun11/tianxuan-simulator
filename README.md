# 天玄修仙模拟器

单人月令回合制开放世界修仙模拟器。你从底层起步，在一座灵脉正在死去的世界里往上爬。

**无胜利条件，无硬性失败。**

**安装步骤**

1. 手机浏览器打开本页，点击上面的 APK 链接下载
2. 下载完成后点击安装
3. 若提示「未知来源」，在设置中允许该来源安装即可

**系统要求**：Android 5.0 及以上

## 关于这个模拟器

- **十个境界，一百级**：凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 返虚 → 合道 → 渡劫 → 大乘
- **月令回合制**：一回合一个月，十二个月一年
- **十条天命主线**：每条七个阶段，错过就等来年
- **八大修真域**：灵脉正在逐年枯萎，凌霄域最先死去
- **道缘系统**：结识的人有自己的仙途，会自己突破、结仇、陨落
- **无强制目标**：你可以飞升，可以开宗立派，也可以什么都不做
