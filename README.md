## 关于这个模拟器

- **九境百级**：炼气 → 筑基 → 金丹 → 元婴 → 化神 → 返虚 → 合道 → 渡劫 → 大乘（凡人不再是境界）
- **修仙百艺九门**：炼丹、炼器、符箓、阵法、御兽、灵植、占卜、琴艺、医术，各有产出与加成
- **月令回合制**：一回合一个月，十二个月一年
- **十条天命主线**：每条七个阶段，错过就等来年
- **八大修真域**：灵脉正在逐年枯萎，凌霄域最先死去
- **道缘系统**：结识的人有自己的仙途，会自己突破、结仇、陨落
- **无强制目标**：你可以飞升，可以开宗立派，也可以什么都不做
